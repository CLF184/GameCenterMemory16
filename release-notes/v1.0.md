首次发布：仅将小米游戏中心上报 JSON 中的 `deviceInfo.totalMemoryKb` 改为 **16777216（16GiB）**。

### 使用要求

- Android 10 及以上。
- 支持现代 **libxposed API 102** 的 LSPosed 框架。
- 启用模块，作用域仅选择 **小米游戏中心 `com.xiaomi.gamecenter`**，完全停止游戏中心后重新打开。
- 模块没有启动器界面。

### 已验证

- 已分析游戏中心 **81.4.3.700** 的设备信息序列化路径。
- Android 真机确认 Hook 命中，序列化后的内存字段改为 **16777216**。
- 本地 Hook 行为测试、APK 结构和 v2/v3 签名校验通过。

只改序列化后的内存字段，保留其他设备信息及原始物理内存。**尚未确认 PC 游戏引擎入口会因此恢复**，服务器仍可能有其他筛选条件。
